# TeamBoard — доска проектов и команд

Веб-приложение для студентов, где можно разместить идею проекта, указать, какие роли нужны команде,
найти интересные проекты по тегам и подать заявку на вступление в команду.

## Назначение и пользовательские сценарии

1. **Поиск проекта.** Пользователь открывает каталог, ищет проекты по названию и описанию, фильтрует их по тегам
   и по статусу «Ищем роли».
2. **Просмотр проекта.** Пользователь открывает карточку проекта: описание, теги, состав команды, открытые и занятые роли.
3. **Размещение идеи.** Автор создаёт проект: название, описание, теги, статус и список ролей, которые нужно найти.
4. **Редактирование проекта.** Автор меняет описание, статус, теги и роли (например, закрывает найденную роль).
5. **Заявка в команду.** Пользователь выбирает открытую роль и отправляет заявку с сопроводительным сообщением.
6. **Обработка заявок.** Автор проекта видит входящие заявки, принимает или отклоняет их. Принятый участник
   попадает в команду, а роль отмечается как занятая. Автор заявки может отозвать её, пока она на рассмотрении.
7. **Профиль.** Пользователь видит свои данные, свои проекты и команды, в которых участвует.
8. **Регистрация и вход** для доступа к созданию проектов и заявкам.

### Статусы проекта

| Статус        | Значение                                |
|---------------|-----------------------------------------|
| `idea`        | Идея — проект только описан             |
| `recruiting`  | Ищем роли — идёт набор в команду        |
| `in_progress` | В работе — команда собрана              |
| `completed`   | Завершён                                |

## Экраны

| Экран                    | Маршрут                | Описание                                                    |
|--------------------------|------------------------|-------------------------------------------------------------|
| Каталог проектов         | `/`                    | Список карточек, поиск, фильтр по тегам и «Ищем роли»       |
| Страница проекта         | `/projects/:id`        | Описание, роли, команда, подача заявки                      |
| Создание проекта         | `/projects/new`        | Форма размещения идеи с ролями                              |
| Редактирование проекта   | `/projects/:id/edit`   | Та же форма с заполненными данными                          |
| Заявки                   | `/applications`        | Вкладки «Мои заявки» и «Входящие» (принять / отклонить)     |
| Профиль                  | `/profile`             | Данные пользователя, его проекты и команды                  |
| Вход / регистрация       | `/login`, `/register`  | Формы аутентификации                                        |
| Страница 404             | `*`                    | Несуществующий адрес                                        |

Скриншоты экранов находятся в каталоге [docs/screenshots](docs/screenshots).

## Стек

- **Frontend:** React 19, TypeScript, Vite, React Router, MUI (Material UI) — библиотека UI-компонентов.

## Запуск frontend

Требуется Node.js 20+.

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173.

Сборка production-версии:

```bash
npm run build
```

На этом этапе экраны работают на демонстрационных данных из `frontend/src/data/mock.ts`.
